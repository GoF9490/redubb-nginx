# Claude 명령어: Update Roadmap

완료된 태스크를 `.claude/docs/ROADMAP.md`에 체크하고 진행 상황을 업데이트합니다.

## 사용법

```
/update-roadmap            # 완료한 태스크 ID를 질문
/update-roadmap T0-1,T0-2  # ID를 바로 지정
```

## ROADMAP.md의 형식 (이 형식을 기준으로 동작)

- 태스크 ID는 `T{Phase}-{번호}` 형식입니다(예: `T0-1`, `T4-3`).
- **진행 현황판**에 태스크마다 한 줄이 있습니다: `- [ ] **T0-1** 제목 (선행: -)`
- 각 태스크 본문(`#### T0-1. 제목`)의 "완료 조건" 아래에 `- [ ]` 체크박스가 있습니다.
- 머리말에 `**📅 최종 업데이트:**`와 `**📊 진행 상황:**` 줄이 있습니다.

## 프로세스

1. `.claude/docs/ROADMAP.md`를 읽는다.
2. 인수가 없으면 미완료 태스크 목록(현황판의 `- [ ]` 줄)을 보여주고 "어떤 태스크를 완료했나요? (예: T0-1 또는 T0-1,T0-2)"를 묻는다.
3. 입력된 ID마다 아래 검증을 한다.
   - 존재하는 ID인가? 아니면 건너뛰고 알린다.
   - 이미 `- [x]`인가? 건너뛴다.
   - **선행 태스크가 모두 체크되어 있는가?** 아니면 사용자에게 확인하고, 확인 없이는 체크하지 않는다.
   - 본문의 완료 조건 중 체크되지 않은 항목이 있는가? 있으면 목록을 보여주고 "모두 충족했는가?"를 확인한다(충족하지 않으면 체크하지 않는다).
4. 검증을 통과한 태스크를 갱신한다.
   - 현황판: `- [ ] **T0-1**` → `- [x] **T0-1**`
   - 본문: 해당 태스크 섹션(`#### T0-1.`부터 다음 `####` 또는 `##` 전까지)의 `- [ ]`를 모두 `- [x]`로 바꾼다.
5. Phase 제목 옆 상태와 `📊 진행 상황` 줄을 갱신한다.
6. `📅 최종 업데이트`를 오늘 날짜(YYYY-MM-DD)로 바꾼다.
7. 변경 결과를 요약한다(체크한 ID, 건너뛴 ID와 사유, 진행률).

## 진행 상황 계산

- 전체 태스크 수 = 현황판의 `- [ ] **T`·`- [x] **T` 줄 수(현재 29개, 고정값으로 가정하지 말고 매번 센다).
- 완료 태스크 수 = `- [x] **T` 줄 수.
- 진행 상황 줄 형식: `**📊 진행 상황:** Phase N 진행 중 (X/Y Tasks 완료)`
  - 모든 태스크가 미완료면 `Phase 0 대기 중`, 한 Phase의 태스크가 모두 완료되면 다음 Phase 기준으로 쓴다.
  - 전체 완료 시 `전체 완료 (Y/Y Tasks 완료)`.

## Phase 완료 표시

- 한 Phase의 모든 태스크가 `- [x]`이면 현황판의 `### Phase N: 제목`에 ` ✅`를 붙인다. 이미 붙어 있으면 건너뛴다.

## 주의사항

- 태스크 ID는 ROADMAP.md에 있는 그대로 쓴다. 번호를 새로 만들거나 바꾸지 않는다.
- 이 명령은 체크 상태와 진행 줄만 바꾼다. 태스크 내용(목표·완료 조건 문구)은 수정하지 않는다.
- 서브 에이전트가 태스크를 마친 뒤 호출할 때는 **완료 조건의 증거(명령 출력 요약)를 보고한 다음**에 체크한다.

## 사용 예시

```
/update-roadmap T0-1

✅ T0-1 완료 체크 (완료 조건 4/4)
📊 진행 상황: Phase 0 진행 중 (1/29 Tasks 완료)
```
